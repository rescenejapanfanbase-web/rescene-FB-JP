RESCENE スケジュール誕生日重複修正 2026-10-03

画像の重複は、Plus Chatの「HAPPY MINAMI DAY」とサイトの自動誕生日予定が別イベントとして扱われたことが原因です。
5人全員の「HAPPY 名前 DAY」を同日の誕生日として認識し、Plus Chatの予定がある場合は自動生成の誕生日を追加しません。
ICS出力は既存の毎年繰り返す誕生日を残し、対応するPlus Chatの単発誕生日を除外します。
日付やメンバーが異なる予定、HAPPY MINAMI DAY カフェイベントのような別イベントは保持します。

アップロード
1. ZIPを展開。
2. GitHubのmainでjsフォルダを開き、ZIP内jsの中のschedule.jsをアップロード。
3. GitHubのscriptsフォルダを開き、ZIP内scriptsの中の5ファイルをアップロード。
4. コミット後、Actions → Sync Schedule → Run workflow → main。
5. 公開が終わったらページを再読み込みし、11月29日の誕生日が1件になっていることを確認。
フォルダを二重に作らず、同名ファイルを上書きしてください。

前回のPlus Chat ID重複修正も同梱済みです。初回適用の場合はPlus Chat予定のIDが移行します。
ICSを手動インポート済みの場合、再インポート時の重複に注意してください。
