4. サイト構成をNotionで管理するアンカー
============================================================
同じ「ホーム・共通表示管理」データベースの「アンカー」で用途を指定します。

nav-xxxx:
グローバルナビゲーション。見出し=表示名、リンクURL=リンク先、補足=ドロップダウン名、表示順=順番。
例: nav-news / 見出し「ニュース」 / リンクURL「news.html」
補足が空欄なら単独リンク。補足が「音楽」なら音楽ドロップダウンへ入ります。

page-xxxx:
固定ページのヘッダー設定。xxxxはファイル名から.htmlを除いた値。
例: page-news / page-members / page-melon-records
見出し、説明、英語ラベル、ボタン文言、リンクURL、画像を管理できます。
トップページは page-index です。

link-xxxx:
HTML側の data-notion-link="xxxx" と連動する管理リンク。
例: link-bubble-app
bubbleの初期リンクは https://apps.apple.com/app/id1556582179 です。

update-xxxx:
サイト更新履歴。
番号=日付（YYYY.MM.DD）、見出し=更新タイトル、説明=内容、補足=カテゴリー、リンクURL=関連ページ、画像=任意。

translation-xxxx:
サイト内の任意文言に確定翻訳を追加。
見出し=日本語の原文（完全一致）
見出し（韓国語）=韓国語
見出し（英語）=英語
記事本文など長文でも登録できます。公開をONにします。

「NOTION-SITE-MANAGEMENT-TEMPLATE.csv」にテーマ、ナビ、固定ページ、bubble、更新履歴、追加翻訳の入力例があります。

5. Language（日本語／韓国語／英語）
============================================================
全公開HTMLへ共通Language処理を読み込みます。ニュース記事ページも対象です。

翻訳の優先順位:
1. Notionの韓国語／英語プロパティ
2. data/language-overrides.jsonの確定翻訳
3. ブラウザのTranslator API（利用可能な環境）
4. 原文表示

ホーム・ニュース・スケジュール・音楽記録では、次のような任意プロパティを認識します。
・見出し（韓国語） / 見出し（英語）
・説明（韓国語） / 説明（英語）
・タイトル（韓国語） / タイトル（英語）
・本文（韓国語） / 本文（英語）
・概要（韓国語） / 概要（英語）
・ボタン文言（韓国語） / ボタン文言（英語）
・イベント名（韓国語） / イベント名（英語）
・記録説明（韓国語） / 記録説明（英語）

プロパティをまだ作っていない場合でも同期は失敗しません。必要な列だけNotionで追加します。
追加翻訳行 translation-xxxx を使うと、ほかのデータベースの文言も一括で確定翻訳できます。

6. 画像の挿入と差し替え
============================================================
原則としてNotionの「画像」ファイル列を優先します。
優先順位:
1. Notionへ直接アップロードした画像
2. 画像パスに指定したGitHub内の画像
3. 既存の予備画像

トップ集合写真:
「ホームヒーロー」行の「画像」セルへ直接アップロードします。
ページ本文、ページカバー、コメント欄へ貼った画像は同期対象ではありません。
同期すると画像内容のハッシュを含む新ファイル名で保存され、PWAやブラウザの古いキャッシュを回避します。

対応形式:
JPG / JPEG / PNG / WebP / AVIF / HEIC / HEIF
HEIC / HEIFは同期時にJPGへ変換します。

8. Melonチャート記録とDeja Vu 13位
============================================================
「RESCENE 音楽記録管理」で次を確認します。
・公開 = ON
・種別 = Melonチャート（Melon / メロンを含む名称も認識）
・タイトル
・曲名
・発売日
・TOP100最高順位 = 13
・表示順

順位は数値列だけでなく、「13」「#13」「13位」のようなテキストも数値として読み取ります。
認識する列名の例:
TOP100最高順位 / Melon TOP100最高順位 / TOP100 Peak / TOP100順位

Deja Vuはdata/records-manual.jsonにも安全用の13位フォールバックを登録しています。Notionの同曲行が取得できた場合はNotion値が優先されます。
変更後は「Sync All Site Content」を実行し、ログの
Melon記録取得: Deja Vu ... TOP100=13
を確認します。

9. GitHub Actionsの使い分け
============================================================
・トップ、テーマ、ナビ、管理リンク: Sync Notion Homepage Content
・複数箇所、記事生成、SEO、Languageまで全部: Sync All Site Content
・スケジュール: Sync Schedule
・YouTube: Sync YouTube Channels

Actionが緑でも表示が変わらない場合:
1. Code画面で最新のchoreコミットを確認
2. 対象JSONと画像ファイルの変更を確認
3. GitHub Pagesの公開完了を待つ
4. Ctrl+F5またはタブを閉じて再表示
5. Actionログで「変更なし」になっていないか確認

10. 変更時の安全設計
============================================================
・同期APIが失敗した場合はスクリプトが終了し、既存データを上書きしません。
・重要時間は最大5回再試行します。
・Notion画像をGitHub内へ保存し、一時URLを公開ページで直接使用しません。
・画像内容のハッシュをファイル名へ付与します。
・自動生成後にJSON、JavaScript、Workflow、HTML、内部リンク、画像寸法を検査します。
・Notionに管理行が未作成でも、ナビ、テーマ、bubbleリンク、既存公開データを安全な既定値で維持します。
