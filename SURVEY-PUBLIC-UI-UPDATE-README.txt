RESCENE JAPAN FANBASE
アンケート公開表示 修正版

修正内容

1. 公開アンケートページからGitHub / Notionの利用が分かる文言を削除
   - ページ説明
   - 回答フォーム案内
   - 「集計について」
   - フッター
   - SEO / OGP説明文

2. 好きな曲ランキングは上位5曲のみ掲載
   - 表示側だけでなく、公開用ランキングデータも上位5曲に制限

3. 「楽曲選択数」を削除
   - 上部の集計カードを4項目から3項目へ変更
   - JavaScriptの表示処理も削除

4. 「全選択票に占める割合」の表示も削除
   - 各曲は「票数」と「選択率」のみ表示

5. 「集計について」を一般ユーザー向けに変更
   - ランキング: 1曲1票で集計し上位5曲を掲載
   - コメント: サイト掲載許可がある回答のみ掲載
   - 更新: 定期的に集計・更新、反映まで時間がかかる場合あり

6. 将来の同期で古い文言が復活しないように修正
   - SEO生成設定
   - 共通フッター設定
   - アンケート統合設定
   - 自動集計スクリプト

反映方法

1. ZIPを展開
2. 中の .github と scripts をリポジトリ最上部へアップロード
3. Commit directly to the main branch
4. Commit changes
5. GitHub → Actions
6. 「Apply Survey Display Update」を開く
7. Run workflow → main → Run workflow
8. 緑色のチェックですべて完了したら公開サイトを Ctrl + Shift + R

完了後の表示

上部:
- 回答数
- 最新回答
- 最終集計

ランキング:
- 1位〜5位のみ
- 票数
- 選択率

集計について:
- 利用している外部サービス名や内部の更新方式は表示しません。

このWorkflowはNotion APIへのアクセスを行わないため、アンケートDBの接続権限に関係なく公開表示の修正だけを反映できます。
