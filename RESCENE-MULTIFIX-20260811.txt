反映方法
========
ZIPを展開して、以下をリポジトリ最上部へアップロードして上書き。

js/discography.js
js/news-engagement.js
scripts/sync-korean-charts-fixed.py
scripts/sync-dejavu-melon-record.py
scripts/inject-news-engagement.py
.github/workflows/rescene-maintenance-bridge.yml

Commit directly to the main branch でコミット。

初回実行
========
GitHub Actions
→ RESCENE Site Maintenance Bridge
→ Run workflow

これを1回実行する。

初回実行で、
・Deja VuをNotion値へ更新
・Genie Dailyが前日分へ更新
・既存ニュース記事へいいね/共有UIを挿入
を行う。

その後は「Sync Notion News」が完了するたびMaintenance Bridgeが続けて動くため、
Deja VuのNotion変更、Genie Dailyの前日分、ニュース新規記事の反応UIを追従する。
