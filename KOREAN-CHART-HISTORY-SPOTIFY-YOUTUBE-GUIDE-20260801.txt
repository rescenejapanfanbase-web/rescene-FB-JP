基準日: 2026-08-01

============================================================
1. 今回の追加内容
============================================================

・가이섬に保存されている過去順位を、初回のみ手動で補完
  対応: Melon TOP100 / Genie Real-time / Bugs Real-time / FLO / VIBE Daily / YouTube Weekly Top Songs
・過去順位と、RESCENE JAPAN FANBASEが今後自動取得する順位を同じ履歴JSONで連結
・同じ集計時点では公式・最新取得データを優先し、過去補完データで上書きしない
・過去データがない期間は推測しない
・順位グラフに「全期間 / 直近90日 / 直近240件」の切替を追加
・長期履歴はブラウザ負荷を抑えるため表示用のみ最大720点に間引き。保存データ自体は削除しない
・サイト上に「過去順位の一部: 가이섬」と出典を明記
・Spotify Top 50 - South KoreaはSpotify公式公開Embedを優先して取得
・Spotify Client ID / Client Secretは基本不要。登録済みの場合だけWeb APIを予備経路に使用
・VIBEは毎時取得をやめ、毎朝7:10に取得
・YouTube Music Koreaは毎日11:30に更新確認。同じ週は重複保存しない
・Spotify Koreaは毎日10:20に取得
・日次・週次チャート専用Watchdogを追加

============================================================

1. 更新用ZIPを展開する。
2. ZIPそのものではなく、中にあるファイルとフォルダをGitHubリポジトリ最上部へ上書きする。
3. .githubは隠しフォルダなので、必ず反映されていることを確認する。
4. Commit directly to the main branchでコミットする。

今回、NotionのデータベースやVariableを新しく作り直す必要はありません。
既存の以下をそのまま使用します。

3. 最初に通常同期を確認
============================================================

GitHub → Actions → Sync Korean Charts → Run workflow

charts欄へ、最初は次を入力して実行してください。

spotify-kr,youtube-kr

成功後、data/korean-charts.json の sourceStatus で次を確認します。

spotify-kr: ok = true
  metadata.sourceMode = official-embed

youtube-kr: ok = true

Spotifyは公式公開Embedを読むため、SPOTIFY_CLIENT_IDと
SPOTIFY_CLIENT_SECRETが未登録でも動作する設計です。

============================================================
4. 過去順位の初回補完（重要）
============================================================

過去順位の補完は自動定期実行ではありません。
가이섬への負荷を避けるため、必要時に手動で1回だけ実行します。

GitHub → Actions → Backfill Korean Chart History → Run workflow

最初の実行:
  dry_run: ON
  songs: 空欄
  charts: 空欄
  delay: 1.8

ログで各曲・各チャートの取得件数を確認します。
この実行ではファイルを保存しません。

問題がなければ2回目:
  dry_run: OFF
  songs: 空欄
  charts: 空欄
  delay: 1.8

成功すると、次が自動コミットされます。

・data/korean-chart-history/*.json
・data/korean-charts.json
・data/korean-charts-data.js
・必要に応じて data/korean-chart-config.json

安全対策:
・アクセス間隔は最低1秒。初期値1.8秒
・最大100リクエスト
・最大3回再試行
・HTTP 429ではRetry-Afterを尊重
・既存の公式取得データを過去データで上書きしない
・取得できない曲やチャートはスキップ
・全失敗時は公開ファイルを変更しない

7. 表示と出典
============================================================

サイトでは、履歴ファイルに가이섬由来の点が含まれる場合、
グラフ下へ次を表示します。

過去順位の一部: 가이섬 / 最新順位: 各チャートの公開情報

가이섬の利用規約にある出典明示へ対応しています。
出典リンクや表記は削除しないでください。

============================================================
8. 想定される制限
============================================================

・가이섬に記録が存在しない期間は補完できません。
・圏外だった時間を推測してnull値として埋めることはしません。
・同名曲が複数ある場合は、Notionの発売日と가이섬の発売日を比較します。
・サイト側のHTML構造変更やアクセス制限により、一部だけ取得できない場合があります。
・Spotify EmbedまたはYouTubeプレイリストの構造変更時は、前回データを維持して失敗表示にします。
・GitHub Actionsから가이섬への接続が拒否された場合、dry-runのログにHTTPエラーが出ます。その場合は無理に連続実行しないでください。
