RESCENE JAPAN FANBASE サイトテーマ管理（Notion）

管理場所
https://app.notion.com/p/23afd46c4c68443d89de65c74f605d68

「テーマ：」から始まる各項目の「値」に、#から始まる6桁のカラーコードを入力します。
例: #ff6fae

設定項目
・テーマ：テーマ名
・テーマ：背景色
・テーマ：背景色2
・テーマ：カード色
・テーマ：カード色2
・テーマ：メインカラー
・テーマ：メインカラー（淡色）
・テーマ：サブカラー
・テーマ：アクセントカラー
・テーマ：ブルーカラー
・テーマ：文字色
・テーマ：補助文字色
・テーマ：ライト背景色
・テーマ：ライトカード色
・テーマ：ライト文字色

反映
通常は「Sync All Site Content」の次回自動実行で反映されます。
すぐ反映する場合は GitHub → Actions → Sync Notion Homepage → Run workflow を実行します。

安全機能
・#RRGGBB以外の値は採用せず、従来色を維持します。
・未入力項目は従来色を維持します。
・ダークモードとライトモードの両方へ反映します。


重要
・テーマ設定行はNotion側で管理します。GitHub Actionsは読み取り専用で、行の自動作成は行いません。
・「テーマ：」から始まる設定行を削除した場合、その項目だけ既定色で表示され、同期自体は失敗しません。
・設定行を誤って削除した場合は、同じタイトルで行を作成し、「種類」を「ページ設定」、「公開」をオンにして値を入力してください。
